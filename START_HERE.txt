WINDOWS QUICK START
--------------------

1. Open this folder in VS Code / Antigravity.

2. Open a terminal and run:

   py -3.11 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install --upgrade pip
   pip install -r requirements.txt

3. Create demo database:

   python seed.py

4. Start:

   python app.py

5. Open:

   http://127.0.0.1:5000
