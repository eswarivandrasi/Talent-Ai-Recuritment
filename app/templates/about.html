Technical Documentation & Methodology

AI-Powered Intelligent Interview & Recruitment System

Project Overview

This project is a full-stack production-style AI/ML web application designed to optimize corporate hiring pipelines. It replaces manual resume screening and preliminary interviews with transparent, automated Natural Language Processing (NLP) scoring engines.

Core AI & NLP Algorithms
1. Resume PDF Text Extraction & Skill Parsing

Processes uploaded PDF resumes using pypdf and pdfplumber. Contact information, education credentials, and years of experience are extracted using regex boundaries. Technical skills are mapped against a centralized database of 150+ standardized technical skills.

2. TF-IDF & Cosine Similarity Job Matching

Resume text and Job Descriptions are converted into term frequency-inverse document frequency (TF-IDF) sparse vector representations. The text similarity is computed using the vector cosine angle:

\[ \text{Cosine Similarity}(A, B) = \frac{\mathbf{A} \cdot \mathbf{B}}{\|\mathbf{A}\| \|\mathbf{B}\|} = \frac{\sum_{i=1}^{n} A_i B_i}{\sqrt{\sum_{i=1}^{n} A_i^2} \sqrt{\sum_{i=1}^{n} B_i^2}} \]

Skill match ratio is calculated as \( \frac{|S_{\text{resume}} \cap S_{\text{job}}|}{|S_{\text{job}}|} \). Unified match score combines text cosine similarity and skill overlap ratio.

3. Multi-Criteria Candidate Ranking

Recruiters can configure dynamic weighting parameters. The composite candidate final score is calculated from stored empirical data:

\[ \text{Final Score} = (w_1 \times S_{\text{resume}}) + (w_2 \times S_{\text{interview}}) + (w_3 \times S_{\text{skill}}) + (w_4 \times S_{\text{experience}}) \]

Default weights: Resume Match (40%), Technical Interview (35%), Skill Match (15%), Experience/Education (10%).

Responsible AI Framework
  • Zero Protected Characteristics: The system does NOT extract, store, or evaluate gender, race, age, religion, political views, or health data.
  • No Facial Emotion Recognition: Hiring recommendations are based solely on text relevance, technical skill matching, and answer evaluation.
  • Decision-Support Guarantee: AI-generated scores are transparent recommendations intended to assist human recruiters, not replace human judgment.
